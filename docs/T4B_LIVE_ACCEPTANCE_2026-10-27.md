# T4B 本机真实验收摘要（2026-10-27）

本机受控候选已取得 WorkBuddy 原队列恢复后交付、DSH 按时交付、共享容量拒绝和人工关闭的真实证据。本文是脱敏结论，不包含任务库、会话标识、账号、原生私有对话或本机路径；原始证据仅保存在本地。本机复核由同一协调者完成，不代表第三方或第二台物理机器验收。

## 本次修复

真实 WorkBuddy 恢复测试中，worker 按领取提示中的 JSON 示例回报，遗漏顶层 `validationRecords`。原示例仅展示 `status/text/artifacts`，没有说明命令记录引用方式；已有实际命令结果不足以替代 worker 自己提交的验证引用，该样本没有被记为 accepted。

领取提示现在展示完整的 `validationRecords` 字符串数组，要求引用本 attempt 有界 exec 返回的真实 `record` 路径，说明成功退出、清理确认和文件未变的条件，以及失败或未执行检查的如实回报方式。它不新增全局“空数组必定拒绝”规则，也不实现 T5/T6 的完整范围保护或独立 reviewId。

回归用例解析实际 claim 提示的 JSON 示例，再将其送入现有读入/回报/证据验证链路，避免测试手写完整回报而掩盖示例遗漏。编译产物由 TypeScript 实际构建，快照清单由官方脚本生成；为使现有 CI 的提交产物一致性检查和干净检出入口可用，本次收尾同步这些产物，不手改编译代码或哈希。

| 场景 | 结果 | 边界 |
|---|---|---|

| DSH 选模及正常交付 | 用户明确选择 wb-proxy / deepseek-v4.1-flash / low；原生有效配置和请求证据匹配；真实工具、回报及停止后 accepted | 费率未知、可能计费；原生会话是明确创建的空测试会话，不冒充原子准入步骤 |

| 跨执行器共享容量 | 真实 DSH 工作流占用同一 TaskStore 时，WorkBuddy 准入返回 CAPACITY_OCCUPIED；准备调用数 0、无竞争任务 | 是准入负例，不是第二个 WorkBuddy 模型任务；不控制用户手动运行的独立旧网关 |
| 人工关闭及重放 | 实际预览确认后关闭，保留失败历史并释放容量；同键重放、变参冲突及关闭围栏检查通过 | 不凭 idle、超时或客户端 stopped/approved 释放；旧 send 已保存成功回执仍按 T4A 重放，不等于业务 accepted |

DSH 正常案例独立检查了精确内容、LF/BOM、受保护 README、全部实际文件范围和稳定哈希，并先审阅当前脚本再有界重跑 Node 校验，退出码 0。生产 SDK 随后记录 accepted。最后的精确 send 重放没有原生变更调用，任务/操作/运行快照不变。

正常 accepted 的关闭事实使容量可由下一受控准入原子回收；物理容量行仍可存在，不将“可回收”写成“行已删除”。人工 close 实际删除占用行，两种情况分开核对。

## 失败历史与监督修正

- 早期 WorkBuddy 样本有未声明 metadata、缺少回报字段、领取路由分流和未唤醒即过期，均保留原失败或取消结论，没有扩大旧 scope、补写 worker 报告或恢复预算。
- 前一 DSH 样本有两次原生 TIMEOUT 内部重试，实际完成于 09:12:43，晚于原 08:54:54 截止；工具和文件即使正确也未 accepted。用户针对实际预览确认后才关闭，保留迟到成果与审计。不能描述为“按时完成但观察较晚”。
- 分段监督查询的一次自动权限审批审查超时，查询命令没有执行；只按工具允许重试一次。模型期间在原生继续运行，暴露了验收工具未独立维持截止取消的问题。
- 私有验收工具改为同一已批准前台进程内派工并持续监督，按原绝对期限触发取消并等待停止证明。四项离线用例覆盖正常停止、同步等待期间到期、无停止证明和同步失败。新的真实 DSH 案例提前完成，未触发取消；因此真实到期取消分支仍未覆盖。该工具不作为生产后台守护功能发布。

## 源码验证与未覆盖项

构建、类型检查、源码回归、提交产物一致性和快照按关联 PR 的当前提交检查结果登记；旧提交的 CI 结果不能替代当前修复。本次未更改依赖、模型政策、历史契约、原生权限或全局 MCP，也没有用原始真实数据制作公开测试 fixture。

收尾本机回归与 CI 使用相同四组测试，共 671 项：明确指定隔离发现路径后，659 通过、7 跳过，5 项 Windows 命令 helper 用例受本机未签名脚本执行策略阻止。没有降低策略或将这 5 项改为跳过；当前提交的 Windows CI 另行核对。首轮因本机多安装目录导致的自动发现拒绝也保留日志，不计为通过。构建、类型检查、433 文件快照、6 份技能副本及 25 步 MCP/HTTP 冒烟在本机通过；222 个源码及可执行 JS/声明文件与已真实验收的候选逐文件一致，位置相关 source map 另外由实际构建生成。

事务竞争、回滚、准备阶段证明、旧 token/attempt、半写回执和在途调用围栏的完整矩阵仍属隔离自动验证，不将每项都声称为真实桌面故障注入。DSH 实际返工及全部恢复故障、真实到期取消、第二台 Windows、最终账单和代理背后的物理模型未由本轮验证。T5/T6 文件保护与 review、T7 面板/自动策略未交付。

本机候选运行与源码交付不等于合并或正式发布；本阶段不自动升级既有安装、重派历史任务或开始 T5。恢复语义见 [T4B 设计](T4B_OPERATION_RECOVERY.md)，本地入口见 [恢复操作](../gateway/docs/OPERATION_RECOVERY.md)。
