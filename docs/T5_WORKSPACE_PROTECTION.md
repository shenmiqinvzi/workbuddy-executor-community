# T5：工作区基线与文件保护

基线为已完成 T4 的 main `7c27953`。本阶段只实现文件范围、原有改动保护和两执行器共用的验收关口；不实现 T6 reviewId、Web 写接口、OS 沙箱或自动部署。实现遵循以下设计。

## 持久事实与执行顺序

新工作流在任何模型准备/派工前，将原始工作区库存、契约/提交摘要、根目录身份、范围、明确排除项及 Git 原有改动保存到同一 TaskStore。保存文件类型/大小/哈希，不存文件内容。基线只写一次，重连或返工不覆盖。每个 attempt 另外保存输入库存，以原工作流基线检查累计增量，不能把上一轮越界重新当成干净基线。

新结构化契约按既有 exact-file / directory/** 范围执行，交付物与预先许可 metadata 分开。旧无结构化范围的新调用只获得只读范围，不推断自然语言授权写入；已有历史任务不回填基线。没有可靠基线的历史任务仍可查询、取消和按 T4 恢复/关闭，但不能以本阶段的新验收关口通过或自动续派。

现有 WorkBuddy MCP/SDK 的非契约 send 可显式提供同一格式的 scope；它进入原始提交摘要和持久基线，不能由返工扩大，也不伪造 vnext-1/vnext-2 agreement。未提供时仍只读。完整 TaskContract 不得与该简化 scope 覆盖项混用；DSH 继续要求既有 vnext-2 契约和实际授权方案。模型选择、历史免费限制与方案授权规则不因本阶段改变。

准备前后的路径检查防止 await 期间改换目录或静默接受新的输入。程序自己接收的 cwd、命令 inputs、交付路径必须在原工作区内，并拒绝链接/重解析、硬链接别名和 Windows 歧义路径。任意 shell 参数不能普遍解析为文件操作，不将此约束冒称进程文件系统沙箱。

## 库存、归属与并发

比较新增/修改/删除/重命名、二进制、大小写和空目录；重命名同时检查两端。遍历不跟随 symlink/junction，新增或变化的链接不能验收。默认明确排除 .git、node_modules 及服务自有数据库/runs；排除不授予写许可。声明覆盖 node_modules 时单独扫描，资源上限或权限错误时拒绝。Git控制数据和服务自有状态不接受工作区写授权。

Git原有dirty、暂存、未跟踪及忽略的现存文件作为保护项；读取Git时禁用可选锁、fsmonitor与外部filter，不刷新或还原用户索引。非Git目录保存实际字节基线，不能凭空声明具有Git未提交状态。扫描有文件数、字节数和时间上限；读取/竞态错误为checker_error，绝非passed。不能可靠归因的原有改动冲突保持冲突，不自动回滚用户文件。

## 检查与查询

显式同步/独立验收路径保存绑定 task/attempt/原基线的范围检查结果，并推进事实revision。HTTP GET只读取已存事实，不扫描、不补写基线或报告。验收前再次核对当前库存，发生变化则拒绝旧检查；失败结果与原工作流容量保持，不产生accepted或伪造停止。

库存覆盖只限登记工作区，排除项显式返回；能认证的结构化原生文件操作另行记入路径证据。未知原生工具或shell对工作区外的任意写入不具备全面可见性，始终保留此限制。

服务自有数据库、sidecar 和 runs 的排除位置先解析到真实路径，包含尚未创建目标的既有父目录；Windows 长短目录别名不能把自身 SQLite 写入误判成用户改动。仅排除这些精确自有位置，其相邻用户文件仍受范围检查。

受控输入/成果的 Windows 短名先核对真实归属；词法上位于外部的别名只有在实际落回原工作区、且原路径所有组成部分不含链接/重解析点时才允许。外部 junction/symlink 指回工作区不属于短名兼容，仍拒绝；内部路径展开后再按实际相对文件名检查原 scope。

## 固定验收

1. 两执行器在原生副作用前保存基线，扫描失败/危险范围无模型请求；重复调用不刷新基线。
2. 累计增量正确分类新增、修改、删除、文件重命名、二进制和最小metadata；额外隐藏文件拒绝。
3. 原dirty/暂存/未跟踪内容保持，缺失/篡改/错身份基线拒绝；返工不清除旧越界。
4. Windows中文/空格/大小写、..、UNC、ADS、保留名、symlink、junction、hardlink、缺失目标及检查后换路径均验证。
5. 库存变化和并发冲突使旧检查不可验收；checker_error不通过，失败不释放容量。
6. 同一保护关口覆盖WB、DSH及现有受控验收入口；旧历史只读/取消/恢复不被伪造迁移。
7. GET不写文件/库、不执行Git、不调用模型；检查覆盖和排除项明确。
8. 构建、类型、受影响回归、独立干净检出与当前提交CI分开记录；不伪装真实模型/异机验收。
