## 实施

1. 只根据已给任务信息、明确范围/时限、真实目录能力和当前/原政策筛选direct、执行器/来源/精确模型/推理候选。无需路由而扫全项目、另调付费模型或编造质量分不允许。
2. 返回推荐理由、排除原因、缺失信息、资源引用与局限、统计样本量/时间窗；不把在线当可执行、声明关联当真实路由、未知当充足/零。硬费用上限无法保证时明确拒绝该要求。
3. 用户显式指定优先；选择不可用时显示原因并等待选择，不挑“最便宜”替代。direct不建原生attempt，推荐不等于授权。
4. 接入技能和桌面预览/修改/可信确认，覆盖后生成新plan/revision；执行前重验目录、政策、费用能力、快照新鲜度和绑定漂移，过期/失效不自动换来源。
5. 同一输入/同一能力快照得到确定可审计结果，保留解释版本和引用摘要；后续07可复用评估器但不能复用手动确认作为自动授权。
