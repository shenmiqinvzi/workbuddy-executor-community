# 04：安装、升级回退与发行准备（第一批）

从G0的L04-installation / feat/finish-l04-installation开发。读COMMON/MASTER、A的CANDIDATE_INSTALLATION_READINESS、Windows安装/恢复/部署验收文档及setup实现。任务D7-01/03、D1-01准备，不重做A已交的check/preview/drill。

## 负责范围

拥有installation-readiness/deployment-safety、安装/桌面构建打包专属脚本、相关桌面依赖诊断、Windows安装恢复文档及本线测试。gateway/scripts/package.mjs统一白名单/快照由集成人维护，任何改动给接线请求；根README/ROADMAP用户在途内容不改。

## 实施

1. 将候选网关包与完整可运行桌面安装的依赖缺口说清：Node/生产依赖/.NET/WebView2/架构/WorkBuddy版本、离线/缺失时可执行诊断。源码zip不是完整安装器，不以复制文件冒充可运行安装。
2. 复用setup安全准入，补干净安装、重复安装、旧版升级、失败中断、配置/技能备份、历史保留、卸载恢复、受保护用户后续修改时拒绝覆盖；活动任务/未知停止/常驻服务不能绕过。
3. 支持具体版本可回退的差异计划：文件/哈希/运行目标/配置影响/步骤/失败补救。schema变化不能保证直接降级则设计相容恢复路线、保留原状态，不能“删DB即可恢复”。
4. 只在本线自建隔离目录与合成状态做安装演练，明确“不含真实生产切换”；端口/profile和后台启动失败不放宽准入、不批量杀进程。
5. 整理第三方许可证/依赖声明与缺失，项目许可由权利人决定：提供可选择建议和待决定项，不能擅自添加替别人授权的LICENSE。签名状态如实，不把关闭系统保护列作前提。
6. 给10输出可审查的实际部署步骤模板、版本核对/备份回退和异机依赖检查；给11输出产物种类、限制与用户安装说明。

## 验收

在隔离旧/新安装夹具检验保留.env/data/历史、技能备份和冲突保护、缺依赖/未知架构/不可读状态、缺停止文件/忙服务、损坏zip/摘要错/越界链接、重复/失败回滚/卸载。至少一次从打包解包后的工具执行check/preview/drill，而非只源码单测。
UI/宿主有改则跑C#策略检查和正式壳合成冒烟；绝不冒称真实升级/物理异机已做。
交专项、依赖/许可台账、部署与回退模板、包清单请求；实际生产安装与外部许可决定留10/11。
