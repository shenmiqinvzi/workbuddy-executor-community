# T7D 桌面工作台：开发与验收计划

修订：2026-11-02。本文是 T7D 的当前开发顺序和验收计划；[桌面控制设计](T7D_DESKTOP_CONTROLS_DESIGN.md)规定行为，[恢复证据设计](T7D_PREPARATION_RECOVERY_EVIDENCE.md)规定不确定准备的证据边界，[总体验收](ACCEPTANCE.md)和现有 T4B 规则继续适用。本计划不自动授权模型任务、安装、发布或降低安全门槛。

## 目标与当前基线

保持轻量独立 Windows 桌面工作台，在同一任务身份下完成停止请求、符合预算和停止条件的返工、独立审查与最终验收。界面明确区分报告、原生停止、独立审查、最终验收和恢复中的未知事实；公共 HTTP 保持只读，桌面写操作受本机确认与后端约束。

截至 2026-11-02 核对：PR #22 仍为草稿，源码 head 为 `34fcb1b1d001e1b2fb4c55c89dbbc1d8acc14c48`，对应 Windows CI 成功；尚无已提交 PR 审查。隔离替身验证了桌面控制，独立桌面窗口中的隔离样本验证了审查、验收、停止和重开；返工有模拟执行器证据。真实模型补验在原生准备阶段结果不明，没有记录 attempt 或完整准备回执，未形成模型报告、原生停止和验收证据。没有 attempt 不证明原生准备没有副作用。仅有预览包，不等于更新日常安装。

原任务保留原操作、会话、范围、模型、预算、证据和容量；不删除或直接改写数据库，不换身份重派，不以新任务清除或绕过原任务。其容量限制适用于其所属库和实际共享资源；跨库也不得与可能仍在途的同一原生请求或会话重叠。不存在充分证据时继续阻塞，人工判断不能替代证据。原任务的原模型授权不自动转移到新任务或新轮次。

## 分阶段实施与交付

|---|---|---|
| P0-1 原任务取证 | 先使用只读或明确允许的原操作恢复查询，核对 task/operation/session、原生和 worker 状态、日志与可查询请求终态；确认资料时间及来源，不持续重复已证实无效的重启。 | 有足够匹配证据时先按项目规则准备可审查的原操作恢复或关闭，再由真实本机人员确认；证据不足则保留阻塞并记录无法获取的保证。关闭不代表 accepted 或授权重派。本阶段不以解决旧记录作为其他源码开发的前提。**2026-11-02 已按“证据充分、仍不确定”收口**，逐字决定与复核条件见[T7D P0-1 原任务裁决记录](T7D_P0_1_ORIGINAL_TASK_DECISION.md)。 |
| P0-2 不确定状态与安全围栏 | 在独立桌面工作台上设计并实现可理解的原任务身份、已知阶段、缺失证据、容量占用和允许操作提示；后端仍是唯一判定来源。仅允许真实后端支持且有证据的观察/恢复，不提供绕过或自动重派入口。当前恢复查询的准备阶段诊断已实现；用户界面与端到端验收待做。 | 覆盖无 attempt、无回执、历史无阶段标记、迟到回执、重复提交、双进程/旧版本和重开；确认 UI 与后端一致、无证据时无可执行的关闭或重派，报告/停止/审查/验收分别呈现。 |
| P0-3 原生准备可靠性 | 评估原生端是否支持有持久幂等键、可查询终态和防迟到保证；仅在可验证的协议和信任边界成立时实现可恢复状态转换。否则将限制如实呈现，不从本地异常、空闲或超时推导终态。 | 记录接口与版本证据；替身覆盖发出前后崩溃、进程重启、并发、迟到创建、身份不匹配和事务回滚；涉及真实原生保证时须在相应版本上另验。不能追溯补造旧任务回执。**源码层已交付（2026-11-02）**：协议事实与探针日志见[T7D P0-3 原生准备协议](T7D_P0_3_NATIVE_PREPARATION_PROTOCOL.md)；真实原生幂等与迟到上界仍需另验。 |

## 交付决策与证据

- **源码开发完成**：对应变更有针对性测试、类型/构建、必要快照和对应提交 CI；不代表真实模型完成。
- **预览交付**：允许标记已完成和未覆盖的能力，明确不确定任务会占用容量、环境依赖和已知检查器问题；不得把模拟、CI 或旧版本结果写成真实补验通过。预览范围若排除未验证能力，应确保用户界面和实际能力一致，并经用户明确接受。
- **T7D 完整验收与 PR 收尾**：需要与最终代码和运行版本匹配的真实模型、停止、审查与验收证据，以及适用的审查、CI 和分支保护要求。原方案要求原任务真实补验；若该任务仍缺证，另一项独立验证能否满足交付门槛须在结果和剩余风险明确后取得用户的明确决定，不能自动改变原验收条件。没有该决定时 PR 保持草稿，不能声称完全验收或合并收尾。
- **正式发行**：遵循 [总体验收](ACCEPTANCE.md) 和 [总体设计发布门槛](DEVELOPMENT_DESIGN.md)，真实环境、第二台物理机、安装升级及其他 P0 要求按既定范围分别核验。预览决定不豁免正式发布门槛。

每次完成阶段记录实际提交/运行版本、测试命令及退出码、证据位置、适用范围与未覆盖项；任务报告、native stop、独立 review、accept 和交付决策分别登记。不得宣称节省费用、改变已安装政策或跨环境成功，除非有相应证据。
