# vNext 行为验收场景

以下为完整vNext的目标验收要求，不表示全表已通过。基础执行链路已有部分自动和本机真实证据，当前覆盖与未验证项见[开发进度](PROGRESS.md)。自动测试可使用适配器替身注入故障；涉及原生行为的结论须另附脱敏的真实桌面证据。检查动作与文件结果，不只匹配提示文字。

2026-10-25 新增 C01–C18 为多 Agent 设计的待实现验收；V01–V15 保留，免费限制按任务实际授权政策判断，默认仍是现有精确免费模型。T1/T2 自动验证不代表新场景通过。

| 编号 | 场景 | 必须观察到的结果 |
|---|---|---|
| V01 | 正常修复和必需测试 | 身份、范围正确，停止确认，独立验收后才 accepted |
| V02 | 原生输入等待，详情可用/未知 | 准确显示处理位置或未知；不代批、不重派，期限不延长 |
| V03 | 报告先到、原生仍忙 | 等待停止，accept/rework/new dispatch 均被程序拒绝 |
| V04 | 已取消、停止不明或忙碌会话 | 不恢复已取消任务，不误停其他会话，不释放不确定容量 |
| V05 | 截止后恢复连接及迟到报告 | 原期限和终态保留，迟到报告不可验收，发生与观察时间分开 |
| V06 | 同键重试、不同约定及双进程请求 | 原生只派一次，冲突可解释，结果不明不换键重派 |
| V07 | 文件越界、额外 metadata、用户旧修改 | 本程序处理的越界操作被拒绝，已观测的原生越界交付不能验收；覆盖范围明确，不吞掉旧改动 |
| V08 | 检查后源码改变或旧轮次验收 | EVIDENCE_STALE/STALE_ATTEMPT，没有虚假通过 |
| V09 | 内容正确、表现形式不同 | 按原约定进行语义审查；checker_error 不归 worker 内容失败 |
| V10 | 三轮耗尽、模型未知或不免费 | 无第四次派发、无付费回退、无 UI 绕过路径 |
| V11 | 浏览器刷新、掉线和旧 revision | 恢复原任务，不重复动作，前后端一致 |
| V12 | 数值缺失、重复事件、人工请求/回复 | null 保留，事件不重复计数，人工 episode 和返工/恢复可复算 |
| V13 | Windows 安装、构建及版本切换 | 按 Windows 文档验收；新运行哈希可核对，旧任务不被重放；配置/历史保留，卸载可恢复原技能 |
| V14 | Windows 路径、进程与服务差异 | 记录系统/架构及 WorkBuddy 版本；中文/空格目录、进程归属、真实领取、停止、返工、取消和重连均有证据；服务失败不绕过共用约束 |
| V15 | 第二台 Windows 实机复现与证据分类 | 本机隔离、CI、真实桌面与第二台物理机器分别报告；同一人操作两台机器须如实标记，不冒充独立操作者复现 |

依据：[总体设计](DEVELOPMENT_DESIGN.md)、[接口契约](INTERFACE_CONTRACT.md)。相关 PR 说明实际覆盖的场景、验证方法与未覆盖部分。

## 多 Agent、模型选择与额度验收（目标，均未验收）

| 编号 | 阶段 | 场景 | 必须观察到的结果 |
|---|---|---|---|
| C01 | T3a/T7 | direct、用户指定及自动模式 | 小改可直接处理；用户覆盖优先；direct 不创建虚假原生轮次；automatic 只用有效预授权 |
| C02 | T3a/T4/T7 | 方案预览、确认与并发消费 | 预览不调用模型、不切会话；未回复不启动；旧 revision/过期拒绝；同方案不同 taskId 不重复派工 |
| C03 | T3b | DSH 无会话、多会话和错目录 | 返回精确候选/原因；不选最新会话、不自动造替代会话；已有任务只观察原绑定 |
| C04 | T3b | 用户选择 DSH 模型与推理档位 | 目录、准备读回、真实请求层证据一致；不把 Codex Reviewer 配置当 worker 模型；代理证据层级明确 |
| C05 | T3a/T3b/T4 | 未授权付费、模型缺失或绑定漂移 | 默认免费约束不放宽；拒绝静默回退；运行中不切换；停止未证实保留占用 |
| C06 | T3b/T6 | DSH 正常交付、返工与独立验收 | 原 task/session 及真实 DSH 来源可核对；报告、停止、插件审查、最终 accept 分开；自动审查故障不改写为成功 |
| C07 | T4 | 跨执行器双进程、投递或模型准备结果不明 | 共同遵守容量 1；意图/回执重启保留；旧任务未知不新派、不按 TTL 释放、不切换执行器绕过 |
| C08 | T3c | 网关账号池、Key 路由与共享额度 | 仅核验路由后称任务可用；未核验标网关汇总；同池去重，不称 DSH 独占 |
| C09 | T3c/T7 | 估算、上游报告、耗尽与未知 | 来源/单位/方法可见；null 不等于 0；有触顶证据才称 exhausted；token/积分/货币不相加 |
| C10 | T3c/T7 | 额度源失联、超时和过期响应 | 缓存标 stale；旧响应不覆盖新快照；任务查询/停止独立可用；不自动换来源或停止任务 |
| C11 | T3c/T7 | 刷新资源、后台采集与主动探测 | GET 零任务写入、零模型请求；后台采集有退避；主动探测需独立授权和计量，外部归档写入如实声明 |
| C12 | T7 | 多客户端并发消耗与任务计量 | 无请求关联时任务消耗 null；不能用余额差；重试、worker、审查各自去重，coverage 不完整如实标明 |
| C13 | T3a/T4/T7 | 付费授权与硬费用限制 | 要求硬上限而来源无法控制时拒绝；估算不足不冒充硬限制；免费标签不代表全过程零成本 |
| C14 | T3a/T7 | 方案审计、政策撤回与项目模板 | 原方案版本和用户覆盖保留；派工重新核验政策；模板不复用身份/旧证据、不增加旧预算、不授权部署 |
| C15 | T3c/T7 | 额度连接、面板和导出边界 | 浏览器不持有网关管理密钥；固定登记连接；拒绝任意 URL 代理；日志/事件/导出无凭据与原始账号 |
| C16 | T3a/T4 | schema 与历史数据升级 | vnext-1 摘要/幂等不变；旧解析器拒绝新版；迁移回滚有证据；旧未知来源/实际模型不造值 |
| C17 | T5/T6 | 切换执行器意图、范围与旧验收 | 首期拒绝 task 内换执行器/模型；旧源码/旧轮次证据不可验收；用户改动保护规则两执行器一致 |
| C18 | T3b/T7 | 宿主兼容、质量统计与真实发布 | 记录实际 DSH/代理/运行版本；真实派工/停止有证据；成功率附样本数/时间范围，检查器错误单列，不宣称未测节省 |

C01–C11、C13–C17 为对应功能上线的 P0 门槛；C12/C18 的统计能力按 P1 交付，C18 的真实宿主/停止及运行版本验证仍是发布 P0。先做合成故障验证，再分别登记真实 WorkBuddy、真实 DSH 和代理链路证据；共用模拟适配器不能代替两个执行器各自的原生验收。
