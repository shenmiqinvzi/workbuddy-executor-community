# T7B 独立桌面任务准备与手动派工

T7B 在 T7A 的工作纸界面内增加任务准备、原生确认和请求回执。执行、共享容量、范围保护、停止规则、轮次与验收继续由现有 T4/T5/T6 后端负责。源码与合成验证不等于已升级个人安装或通过真实模型补验。

## 用户流程

1. 在独立桌面工作台选择“新建任务”，主动读取已配置执行器的模型目录和当前可观察费率。打开窗口本身不读取模型、不准备会话、不派工。
2. 选择已有项目目录，填写目标、精确文件或 `directory/**` 范围、独立验收要求、最多轮次和执行时限。留空修改范围为只读。元数据范围可选，不默认开放 `.git`。
3. 明确选择执行来源、精确模型、推理档位。WorkBuddy 未提供推理档位时也须主动选择“未提供”；DSH 还须选择本项目已连接、空闲的原会话，不会自动创建或更换会话。
4. 核对服务器生成的不可变约定。原生确认窗口再次显示完整约定，复选框默认关闭，无默认回车确认。取消不提交；未知费用明确为“可能计费”，时限不是费用上限。
5. 确认后登记唯一请求，后台派工进程使用原 taskId、operationId。窗口关闭后不会重新派工；重开查询原回执，再查看已保存任务。点击“更新执行状态”只观察该入口原已受理任务，不准备模型或重派。

原生接单、报告收到、停止确认与独立验收仍是不同事实。T7B 不提供取消、返工、验收或第三方权限批准。

## 边界与恢复

- 公共 HTTP 服务继续只接受 GET/HEAD；`/workbench/desktop/capabilities` 通过 HTTP 返回 `available:false`，POST 命令为 405。
- 桌面外壳截获精确同源的私有命令资源，使用父子进程 stdio 传递有界 JSON。WebView host objects 和 web messages 仍关闭，外部导航、弹窗、下载、权限请求和框架导航仍拒绝。
- 网页只能提交草稿身份与摘要，不能调用 `commit`、执行任意命令或在确认后替换模型/范围。原生外壳读取服务器约定，确认后才调用内部 commit。
- 目录/草稿有效期为五分钟。提交与后台执行前复核模型、政策版本、观察费率、项目身份和会话；变化则拒绝，不自动换模型或续轮。
- 原有免费模型和 allowlist 政策继续生效；付费或未知费用的选择不能绕过已有部署限制。
- 独立私有 SQLite 回执保留原约定、请求、任务和操作编号，CAS 保证后台进程只认领一次。重复确认复用同一请求；失败或结果不明不自动重试。结果不明时查询原任务和操作，不能以新任务替代恢复。
- 关闭窗口只结束该窗口的查看服务；确认后的后台进程独立。若操作系统终止后台进程，回执可能停留在处理中，不能推断成功、停止或安全重试。
- 任务页的普通刷新只读已保存事实；显式“更新执行状态”沿现有 sync 路径观察原任务，受理不代表已接单或验收。

## 部署前提

派工默认关闭。只有在明确批准部署、核对目标库和现有政策之后，才可为目标安装配置 `WORKBUDDY_DESKTOP_DISPATCH_ENABLED=1`。还必须已有现代任务库表及 revision 字段；旧库被拒绝，桌面入口不会迁移。需要迁移的安装应另行备份、审查迁移及回滚计划，并完成网关部署核验。

回执默认位于当前用户应用数据的 `WorkBuddyWorkbench/dispatch/<安装及库身份>/requests.sqlite`。可用绝对路径 `WORKBUDDY_DESKTOP_STATE_DIR` 指定私有根目录。不要把回执、任务库、runs、profile 或 `.env` 放入源码或公共包。T7A 原安装与已安装技能的政策不得被源码验证自动替换。

预览包仍未签名，Windows 可能显示 SmartScreen 提示。预览不要求降低系统保护。需要 Windows x64、.NET Desktop Runtime 10、WebView2 Runtime、Node.js 与锁定的网关依赖。

## 验证范围

`desktop-dispatch.test.ts` 使用假执行器验证明确选择、范围/预算、费率变化、唯一身份、私有回执和旧库拒绝，并经过真实 TaskApplicationService 的准入及共享容量路径。前端与原生命令测试覆盖只读 HTTP、命令白名单、有界消息和中文 UTF-8 传输。

`test/support/desktop-dispatch-fixture.mjs` 是显式合成实窗夹具，不进入发布包。它要求标记的隔离目录，只能打开目录内的任务库与 runs，所有原生模型/会话操作均为假实现。实窗验证需要持续的合成标记，并分开记录测试入口覆盖与发布文件哈希。

真实补验须另行显示实际模型和费率、取得本轮实际选择，保留失败与停止记录；不能用合成任务、源码测试或旧阶段的通过记录替代。
