# 场景索引（M01–M16）

所有场景定义在 [`src/data/mock/scenarios.ts`](../src/data/mock/scenarios.ts)，共用演示起点 `2026-10-20T01:10:00Z`。

触发方式：

1. 顶栏"场景"下拉框选择；
2. 或直接打开 URL：`?scene=M06`、`?scene=M02&frame=1`（frame 从 0 开始）。

| 场景 | 名称 | 帧数 | 关键帧要看什么 | 关联验收 |
|---|---|---|---|---|
| M01 | 正常流程 | 4 | 第 1 帧等待领取 → 第 2 帧正在执行 → 第 3 帧待验收（报告已到、停止已确认）→ 第 4 帧已验收；验收节点独立于报告 | F03、F04 |
| M02 | 报告先到，等待停止 | 3 | 第 2 帧 `waiting_stop`：报告可读，但页面不出现"已验收"；第 3 帧才进入待验收 | F04 |
| M03 | 原生等待，详情可用 | 1 | 会话标题、工具名、请求摘要、目标路径、处理位置；没有任何代批按钮 | F06 |
| M04 | 原生等待，详情未知 | 1 | 明确"具体请求详情不可用"，不编造权限类型或命令 | F06 |
| M05 | 取消后尚未停止 | 1 | 显示"等待停止确认"而不是"已取消"，取消请求只作为已记录事实 | F07 |
| M06 | 已取消且停止确认 | 1 | 终态"已取消"，没有恢复 / 重试 / 继续入口 | F07 |
| M07 | 到期与迟到报告 | 1 | 显示"已超过期限"；迟到报告可读，但不按按期成功展示 | F07、F10 |
| M08 | 明确执行失败 | 1 | 失败原因来自后端事实；未知项与失败原因分开 | F03 |
| M09 | 执行状态未知 | 1 | 保留最后观测时间与核查说明，不显示为运行中 | F03 |
| M10 | 断线与重连 | 3 | 第 2 帧连接中断：保留旧快照并提示；第 3 帧重连后仍是同一 taskId / attempt / deadline | F08、F09 |
| M11 | 三轮耗尽 | 1 | 第 3 / 3 轮，历史返工事件保留，没有第四轮入口 | F03、F12 |
| M12 | 检查器错误与未知成本 | 1 | `checker_error` 单独展示；成本 / bytes / hash 为"未知"而不是 0 | F11、F16 |
| M13 | 越界文件与用户改动冲突 | 1 | 未授权变化、元数据写入、交付物分别展示，不合并成通过 | F16 |
| M14 | 空列表、筛选无结果与首次加载 | 3 | 第 1 帧加载中、第 2 帧空列表、第 3 帧有任务；筛选无结果时出现"没有匹配的任务"+ 清除筛选 | F03、F13 |
| M15 | 坏数据与未知新状态 | 1 | 未知枚举 → "未知状态，需核查"；非法时间 → "时间未知"；矛盾证据 → 数据不一致提示 | F13 |
| M16 | 极端内容与恶意文本 | 1 | 超长标题、中文/空格文件名、`<script>` 字符串只作为文字显示；无脚本执行、无本机路径打开 | F14、F15 |

## 每帧的通用检查

- 页面持续显示"模拟数据"标记。
- 状态徽标同时有文字与图标，不只靠颜色。
- `null` 显示"未知"，`[]` 显示"已知没有"。
- 时间按本地时区展示，同时保留完整时间提示。
