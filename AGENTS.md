# Project rules

- For each new collaboration task, show the available executor/source/model/reasoning choices and known pricing, then obtain the user's actual selection and confirmation before model preparation or dispatch. An already authorized selection for that same task remains valid.
- Do not preselect a model, require a zero rate by default, or silently substitute another model. Paid and unknown-price models may be explicitly chosen; unknown pricing must be disclosed and never represented as free or a hard spending limit.
- Free-only and allowlist restrictions are optional policies. Preserve both the original task policy and current restrictions; changing defaults does not relax historical task admissions or installed deployment settings.
- Recommendations do not authorize execution. Source development and push do not authorize bridge installation, profile changes, or real task dispatch. Keep source verification separate from live acceptance.
